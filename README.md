# 🔐 EN/DE-CODE

> **Encode the message. Decode the mystery. Understand the logic.**

EN/DE-CODE is an interactive cipher playground designed to make encoding, decoding, and exploring classical ciphers easier and more approachable.

Instead of treating a cipher as a black box, EN/DE-CODE brings the transformation process and its underlying logic into one workspace.

## ✨ Features

- **↔️ Encode & Decode** — Transform messages and reverse supported cipher operations.
- **📋 Copy & Paste** — Move text into and out of the workspace easily.
- **🧹 Clear Workspace** — Reset the input and output when starting again.
- **💡 Helpful Hints** — Get guidance while exploring a cipher.
- **🧠 Cipher Explanations** — Learn how supported algorithms transform text.
- **🎚️ Caesar Shift Control** — Adjust the shift value when using the Caesar cipher.

## 🧩 Explore the Logic

A classical cipher applies a defined transformation to a message. For example, the Caesar cipher shifts each letter by a chosen number of positions in the alphabet.

For a basic Caesar cipher, the encryption rule can be written as:

\[
E(x) = (x + k) \bmod 26
\]

And the decryption rule is:

\[
D(x) = (x - k) \bmod 26
\]

Where:

- \(x\) is the letter's numerical position in the alphabet.
- \(k\) is the selected shift value.
- \(26\) is the number of letters in the English alphabet.

The shift value controls how the message is transformed. Explore different values and compare the results to see the logic in action.

## 🚀 Getting Started

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.
3. Choose a supported cipher and enter your text.
4. Select **Encode** or **Decode**.
5. Explore the hints and explanations to understand the transformation.

## 🎯 Why EN/DE-CODE?

EN/DE-CODE combines a practical text-transformation workflow with an educational experience. It is useful for experimenting with classical ciphers, understanding their mechanics, and learning the fundamentals of substitution-based encoding.

## ⚠️ Security Note

Classical ciphers such as Caesar are useful for learning and experimentation, but they are not suitable for protecting sensitive information.
